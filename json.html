DATA TECHNOLOGY

JSON ◆

Un formato utilizado para almacenar e intercambiar información entre aplicaciones.

01

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato ligero utilizado para representar y transportar datos.

Es muy utilizado en páginas web, aplicaciones y APIs para enviar información entre clientes y servidores.

02

Clave y valor

{
  "nombre": "GTA V",
  "genero": "Acción",
  "año": 2013
}

ESTRUCTURA

OBJETOS Y ARREGLOS

01

Objeto

Contiene información mediante pares de clave y valor.

02

Arreglo

Permite almacenar varios valores dentro de una lista.

03

APIs

JSON permite intercambiar información entre aplicaciones.

DATOS DE UN VIDEOJUEGO
