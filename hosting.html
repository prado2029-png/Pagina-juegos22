WEB HOSTING

El servicio que permite almacenar un sitio web y hacerlo accesible desde Internet.

TIPOS DE HOSTING

¿DÓNDE VIVE TU PÁGINA?

01

Compartido

Varios sitios web utilizan los recursos de un mismo servidor.

02

VPS

Un servidor físico se divide en servidores virtuales con recursos asignados.

03

Nube

Utiliza diferentes servidores para ofrecer recursos y disponibilidad.

DESPLIEGUE

¿QUÉ ES VERCEL?

Vercel es una plataforma que permite desplegar proyectos web y hacerlos accesibles desde Internet.

Puede conectarse con un repositorio de GitHub para publicar automáticamente los cambios.
